# Layerforge — independent website concept

Self-initiated Pixaloom portfolio study for a fictional 3D printing and scanning brand. Not commissioned client work, an operating business or a commercial storefront. Navigation and catalogue interactions demonstrate interface design; forms are local demos and send nothing. Sample prices and specifications are illustrative. The original website layouts and photographic assets are retained with the fictional brand identity. Portfolio images are browser captures of this app.

Run `npm ci`, `npm run build`, and `npx tsc --noEmit` to validate. Publication targets are verified separately in the application handoff.

## Publication destination

The independent concept uses `https://layerforge-concept.cameronfalck03.workers.dev` as its public demonstration address. The site is a fictional, self-initiated study; it provides no commercial checkout, enquiries or client endorsements. Publication is verified by reading the unauthenticated pages and checking navigation, images and concept disclosures.
